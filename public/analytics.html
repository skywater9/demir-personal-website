Includes arrival, first action, clicks (even on non-buttons), screens and choices, engine/steering/thruster presses and releases, throttle changes, docking attempts, landings/refueling, deliveries, results, leaving and returning. No names, email addresses, passwords, typed text, or full URLs are collected. Observed time is last event minus arrival; gameplay time is reported separately on game events.

Uploads run every 5 seconds. Offline rows retry from this tab after refresh. Browser shutdown can prevent the final upload; visible-page heartbeats every 20 seconds reduce the unknown gap. An empty timeline means no events are saved yet. Spark quotas and blockers can stop uploads; the game footer reports pending data. The older Functions-based heatmap is not enabled by this event log.
